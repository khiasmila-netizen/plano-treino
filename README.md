# Plano Treino

App de treino em casa: 3 dias de glúteos (segunda, quarta e sexta) e 2 de tronco (terça e quinta), com séries, temporizador de descanso, cargas, medidas e progresso.

Endereço: https://khiasmila-netizen.github.io/plano-treino/

Instalar no Android: abrir o endereço no Chrome → ⋮ → Instalar app.

Os registos ficam guardados no telemóvel. A app mostra, só para leitura, o peso e a meta registados na app Dieta.
